## 🔧 What I'm Working On Now

**Event-Driven Public Complaint Management System**
Citizen complaints are ingested via Kafka, classified by an ML model, and routed to the right government department — all in near real-time. Built because government complaint portals are broken and the backend layer is where the fix starts.

`FastAPI` · `Apache Kafka` · `PostgreSQL` · `PyTorch` · `Docker`

## 💡 A Few Things I've Learned the Hard Way

- Kafka is not a queue. Treating it like one will humble you.
- A model that works in a notebook is not a deployed model.
- System design is mostly about what you *don't* build.
